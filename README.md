# PDF Document Agent

Учебный интеллектуальный агент для ответов на вопросы по содержимому PDF-документа.

## Текущий статус

Готов первый вертикальный срез:

- принимает путь к PDF;
- проверяет входной файл;
- извлекает текст и структуру в Markdown через Docling;
- обрабатывает text-based PDF;
- распознаёт image-only PDF через macOS Vision OCR (`ocrmac`);
- возвращает имя документа и количество страниц;
- сообщает понятную ошибку для отсутствующего, неверного или пустого документа.

Следующий срез: разбиение документа на фрагменты, поиск релевантного контекста и ответ LLM с указанием страниц-источников.

## Поток данных

```text
PDF
  ↓
валидация файла
  ↓
Docling
  ├── встроенный текст → структурированный парсинг
  └── изображение      → OcrMac (ru-RU + en-US)
  ↓
Markdown + число страниц
```

## Требования

- macOS 10.15 или новее;
- Python 3.13;
- [uv](https://docs.astral.sh/uv/).

OCR намеренно использует Apple Vision: на реальном русском скане он дал приемлемый результат, тогда как проверенные RapidOCR и EasyOCR не прошли smoke-тест качества. Текущая версия проекта поэтому ориентирована на macOS.

## Установка

```bash
uv sync
```

При первом запуске Docling может скачать модели анализа структуры документа.

## Запуск

```bash
uv run pdf-document-agent /путь/к/document.pdf
```

Альтернативный запуск:

```bash
uv run python -m pdf_document_agent /путь/к/document.pdf
```

## Тесты

```bash
uv run pytest -q
```

## Известные ограничения

- OCR может допускать опечатки на маленьком, размытом или низкоконтрастном тексте;
- пока нет поиска по фрагментам документа;
- пока нет подключения LLM и диалога;
- пока нет пользовательского веб-интерфейса;
- качественный OCR в текущей конфигурации не переносим на Linux/Windows без замены OCR backend.
